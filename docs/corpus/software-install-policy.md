# Software Install Policy

Employees may only install software from the approved catalog in the software portal. Installing software from personal sources or unverified downloads is prohibited.

Administrative rights are required for installs and are granted to Engineering roles only. Requests for admin rights go through the help desk and require manager approval.

New software enters the catalog after a security review by the AppSec team, which takes up to 10 business days. Software without an active license is removed from the catalog at the next quarterly review.

Trials and free tools still require catalog approval. Shadow IT discovered during audits is uninstalled within 5 business days unless it is retroactively approved.

Browser extensions count as software installs and must come from the approved extension list.
